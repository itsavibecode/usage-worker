# Email previews

Static HTML renders of the email templates in `../src/index.js`.

Generated by:

```
node scripts/generate-previews.mjs
```

Re-run any time after changing the templates to refresh the previews.

## Files

| File | Source function | Status |
|---|---|---|
| `reminder-email.html` | `buildReminderEmail()` | **Live** — sent by the daily cron when products approach reorder threshold. |
| `reminder-email.txt` | Same, plain-text body | Same. |
| `recall-email.html` | `buildRecallEmail()` | **Not yet wired into the cron.** Template ready for the deferred v2 of the recall-alerts feature. |
| `recall-email.txt` | Same, plain-text body | Same. |

## Why these are checked in

They're a visual contract — anyone reviewing a change to the email
templates can see what the change does without setting up a Resend
test send or wrangler dev session. Keep them in sync with the source
by re-running the generator script.

## Adding sample data variations

Edit `scripts/generate-previews.mjs` and add more sample arrays.
The `sampleReminders` and `sampleRecalls` constants there are designed
to cover all severity tiers / status states so the previews exercise
every visual branch (amber + red reminder pills; Class I + II + III
recall stripes).
